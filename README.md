# AI Tourist Safety Risk Predictor

### CODEARAMBH 2.0 — Team VERTEX

A working MVP of an AI-powered Smart Tourism solution that provides tourists with a **dynamic safety score** for selected destinations.

The MVP considers **live weather conditions, time of day, area risk patterns, crowd density, and historical incident patterns** to estimate the current safety level and suggest a safer alternative destination.

## 🚀 Live MVP

https://harishgit0.github.io/ai-tourist-safety-mvp/

## ✨ MVP Features

- Dynamic safety score (0–100)
- Safe / Moderate / High Risk classification
- Live weather data using Open-Meteo
- Time-based risk analysis
- Destination risk comparison
- Safer alternative recommendation
- Simple and responsive interface

> **Note:** Crowd density and historical incident values are currently modeled placeholders in this MVP. Live data integration and the complete AI/ML pipeline are part of the planned full solution.
